::::prose-p3
The client approached us with a ready UX/UI design and the need to implement a new website. The existing site did not support sales to the expected degree - in short, it was getting in the way.

The new Reequest site was meant to be fast and lightweight, without an extensive WordPress back end, with a polished desktop and mobile version. A key requirement was the ability to independently develop content and manage the site. The client expected the site to be tested across various browsers and on iOS and Android devices. An additional condition was the deadline: the new site had to be ready before an upcoming trade fair.

### **Website implementation in Nuxt Studio**

::::prose-p3
To combine site performance with the ability to develop content independently, we built a Fullstack application in Nuxt, based on the Nuxt Studio module. Content is stored in Markdown files in a GitHub repository, and the Reequest team can edit it visually directly on the site. Using the Nuxt Studio module, we built components and made it possible to change section content and media, and to duplicate pages without touching the code. Thanks to the GitHub integration, every change is visible and saved in the history. To generate the site as static HTML, we used prerendering and configured Nuxt SEO, a sitemap and a robots.txt file.

As part of the implementation, we also built a blog, a mega menu, an FAQ section, a Calendly integration and a video player. Case studies can be automatically displayed on service pages; we also implemented galleries and video playback in the case studies section.

### **Result of work**

::::prose-p3
Based on the UX/UI design provided by Reequest, we built a lightweight, fast-loading website prepared to support the agency's sales activities. Before publication, we refined the implemented views and functionalities, and the client verified their compliance with the design. After the site launched, we tested its performance across various browsers and on iOS and Android devices. We also connected analytics integrations and tools supporting contact with customers, including a chatbot and a meeting scheduler.

After the team was trained, Reequest can now independently develop the site in the Nuxt Studio module: update content, use the prepared components and create new subpages without involving a developer for every change. We carried out the implementation on a tight schedule, which meant the new site was ready before the upcoming trade fair.
